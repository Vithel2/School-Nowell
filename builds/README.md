# Тестовая Android-сборка 0.1.4

`School-Nowell-debug.apk` — офлайн-приложение School's Nowell для Android 7.0+ в альбомной ориентации. Это debug-сборка, не публикация в Google Play. Нативная установка на физический телефон не проверялась.

Версия 0.1.1 исправляет альбомный интерфейс телефонов 20:9: меню и карточки помещаются в экран, пауза показывает действия сеткой, настройки доступны без длинной прокрутки, диалог занимает меньше места. Исправлены касания после свайпа и перехват нажатий закрывающимися окнами. Прежний идентификатор приложения и сертификат подписи сохранены; обновление предназначено для установки поверх версии 0.1.0.

В `screenshots/` находятся снимки мобильного браузера с размером области 800 × 360 и плотностью 2×. Это иллюстрации проверенной разметки, а не снимки физического iQOO. Проверены восемь альбомных размеров, десять маршрутов с сенсорным управлением и отдельные проверки жестов. Android-эмулятор без KVM не завершил загрузку; нативный запуск новой версии не подтверждён.

Пакет собран Cordova 12 / cordova-android 13, SDK 34, JDK 17 и Gradle 8.7. Проверены подпись APK v2, целостность ZIP, Android manifest, соответствие SHA-256 исходного `Prototype.html`, наличие Cordova runtime и всех 46 медиафайлов. Подготовленный веб-пакет прошёл десять сюжетных маршрутов в Chromium.

Для проверки скачанного файла используйте сумму из `School-Nowell-debug.apk.sha256`. Для повторной сборки из корня репозитория: `bash scripts/setup-android.sh`, затем `npm run build:apk`.

Версия 0.1.2: собственная иконка SN вместо робота, новый осенний начальный экран, четыре действия в паузе, компактные настройки без прокрутки, видео без стандартной панели плеера. Пакет и ключ подписи прежние; версия предназначена для обновления поверх 0.1.1.

Версия 0.1.3: исправлено «сами не свои» и отделение закрывающей кавычки при разбиении реплик; убран преждевременный переход к школе в тексте на фоне лисы. Сцены лисы и действия с косой проходят без фонового саундтрека. Три кадра действия с Варей сменяются автоматически без комментариев до крика. Кнопки стенда получили перспективу. Добавлен tests/story_fixes.py.

Версия 0.1.4: 17 новых кадров во вступлении Серёги, новый кадр Тимофея после пощёчины и обратное направление перспективы кнопок. В пакете 64 медиафайла. Проверены порядок всех новых сцен, десять сюжетных маршрутов и восемь размеров мобильной разметки; физический телефон недоступен.
