# School's Nowell

Браузерный прототип визуальной новеллы v7 на русском языке. Две истории: «Жизнь Тимохи» и «Серёга».

## Запуск

Из корня репозитория, с установленным Python 3:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `Prototype.html` через этот локальный HTTP-сервер в браузере. Основной прототип содержит встроенные изображения, две музыкальные дорожки и видеозаставку; npm, сборка, база данных и ключи API ему не нужны. Для звука может потребоваться нажатие на экран заставки.

## Управление

- Клик, пробел, Enter, стрелка вправо — продолжить текст.
- Цифры — выбор ответа.
- A — авторежим, S — перемотка, H — скрыть интерфейс.
- L — история, M — звук, Esc — пауза.
- На сенсорном экране: свайп вверх — пауза, вниз — скрыть интерфейс, вправо — продолжить.

Прогресс, настройки и избранное хранятся в `localStorage` браузера. Используйте один и тот же адрес и порт, чтобы видеть прежнее сохранение.

## Встреча с Варей

В истории «Жизнь Тимохи» на перемене выберите «Выйти в коридор». После встречи с одноклассниками появится новая развилка: дёрнуть Варю за косу или пройти мимо с комплиментом. Пять кадров встроены в HTML, поэтому игра по-прежнему работает одним файлом. Все 11 изображений из дополнительного архива, включая макеты с готовыми надписями, сохранены без изменений в `Location/VaryaTimofey/`.

После окрика Вари показан чёрный кадр с текстом: его минимальная длительность — 2,2 секунды, в том числе при перемотке. Главное меню использует неподвижный фон. Кнопка продолжения оформлена каменной плашкой с названием сохранённой истории. Обновлённые настройки показывают значения ползунков, а экран загрузки — реальный прогресс подготовки изображений и кнопку повтора при ошибке.

## Содержимое

- `Prototype.html` — актуальный самостоятельный прототип.
- `Buttons/`, `Layout/`, `Location/` — исходные кнопки, макеты и фоны.
- `Musics/`, `Video/` — исходные аудио и видео.
- `Some game mockups on paper/` — фотографии бумажных макетов.
- `Archive/` — прежние HTML-версии и исходный ZIP; содержимое ZIP сохранено внутри архива.
- `ANALYSIS.md` — анализ структуры, сюжета и ограничений.

Все 73 файла из предоставленного RAR перенесены в корень репозитория с сохранением путей внутри папки `Schools Nowell`, имён и содержимого. Сам транспортный RAR не добавлен, его содержимое представлено распакованными файлами.
