# School's Nowell

Браузерный прототип визуальной новеллы v7 на русском языке. Две истории: «Жизнь Тимохи» и «Серёга».

## Запуск

Из корня репозитория, с установленным Python 3:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `Prototype.html` через этот локальный HTTP-сервер в браузере. Основной прототип содержит встроенные изображения, восемь музыкальных дорожек, видеозаставку и запись Тимофея с лисой; npm, сборка, база данных и ключи API ему не нужны. Для звука может потребоваться нажатие на экран заставки.

## Управление

- Клик, пробел, Enter, стрелка вправо — продолжить текст.
- Цифры — выбор ответа.
- A — авторежим, S — перемотка, H — скрыть интерфейс.
- L — история, M — звук, Esc — пауза.
- На сенсорном экране: свайп вверх — пауза, вниз — скрыть интерфейс, вправо — продолжить.

Прогресс, настройки и избранное хранятся в `localStorage` браузера. Используйте один и тот же адрес и порт, чтобы видеть прежнее сохранение.

## Встреча с Варей

В истории «Жизнь Тимохи» на перемене выберите «Выйти в коридор». После встречи с одноклассниками появится новая развилка: дёрнуть Варю за косу или пройти мимо с комплиментом. Пять кадров встроены в HTML, поэтому игра по-прежнему работает одним файлом. Все 11 изображений из дополнительного архива, включая макеты с готовыми надписями, сохранены без изменений в `Location/VaryaTimofey/`.

После окрика Вари показан чёрный кадр с текстом: его минимальная длительность — 2,2 секунды, в том числе при перемотке. Главное меню использует неподвижный фон. Кнопка продолжения оформлена каменной плашкой с названием сохранённой истории. Обновлённые настройки показывают значения ползунков, а экран загрузки — реальный прогресс подготовки изображений и кнопку повтора при ошибке.

## Тестовый APK

Текущая версия — **0.1.1**, с исправленным альбомным интерфейсом для широких телефонов iQOO/realme. Меню и карточки подбирают размер по высоте экрана; пауза содержит все основные действия в сетке, настройки — в двух колонках. В диалоге остаётся одна крупная кнопка меню, а авторежим, перемотка, история, скрытие панели и избранное доступны из паузы. Сохранены прежний пакет и сертификат подписи для обновления поверх 0.1.0. Примеры экранов — в `builds/screenshots/`.

Готовая Android-сборка: `builds/School-Nowell-debug.apk`. Это офлайн-приложение в альбомной ориентации для Android 7.0 и новее, с тестовой подписью. Установка и работа на физическом устройстве отдельно не проверялись.

Подход взят из `Vithel2/arseniy-god`: Cordova 12, cordova-android 13, Android SDK 34. Для Linux x64 с Node.js 20+ и Python 3.12+:

```sh
bash scripts/setup-android.sh
npm run build:apk
```

Подготовка устанавливает проверенные по официальным контрольным суммам JDK 17, Gradle 8.7 и Android command-line tools; принимает стандартные лицензии Android SDK и устанавливает SDK 34. В облаке инструменты и кэши хранятся в `/workspace/.nowell-tools`. Для другого места задайте `NOWELL_ANDROID_TOOLS`. При наличии прокси среды Java использует его и предоставленный средой CA с сохранением проверки TLS. Ключи и пароли для тестовой сборки не нужны.

`scripts/prepare-android.py` создаёт игнорируемую папку `www/`: извлекает встроенные медиа в локальные файлы, сокращая HTML для WebView, и записывает SHA-256 исходника в `build-info.json`. Сам `Prototype.html` остаётся автономной браузерной версией. После сборки подпись APK проверяется автоматически, рядом создаётся файл SHA-256. `www/`, `platforms/`, `plugins/` и `node_modules/` — генерируемые каталоги. В GitHub Actions доступен ручной workflow `Build test APK`; он выдаёт APK как артефакт.

## Проверка мобильного интерфейса

После `npm run prepare:web` запустите локальный HTTP-сервер из корня репозитория. Проверки требуют Python Playwright (`python -m pip install -r tests/requirements.txt` и `python -m playwright install chromium`):

```sh
python tests/mobile_layout.py
python tests/mobile_touch.py
python tests/mobile_routes.py
```

По умолчанию используется `http://127.0.0.1:8765/www/index.html`. Для другого адреса задайте `NOWELL_TEST_URL`, для установленного браузера — `CHROMIUM_PATH`. Проверяются восемь альбомных размеров, границы меню и кнопок, отсутствие прокрутки основных панелей на целевых телефонах, однократное продвижение при касаниях и свайпах, действия паузы и десять сюжетных маршрутов. Нативные события паузы, возврата и кнопки «Назад» проверяются в браузере программно; это не заменяет установку на физическое устройство.

## Музыка и запись с лисой

Сюжетные изображения сохраняют полный кадр; только три сцены слегка увеличены по авторскому запросу: сборы Тимофея — 8%, дорога — 8%, звонок на перемену — 6%. Если формат экрана отличается от формата иллюстрации, по краям остаются чёрные поля. При входе в историю фон плавно проявляется, затем появляется диалог. Музыка меняется перекрёстным затуханием за 1,8 секунды; переход к тишине занимает 0,9 секунды. На первом чёрном кадре после удара воспроизводится `Sounds/slap.mp3`; отключение звука учитывается. Кнопка продолжения использует встроенный кириллический Montserrat, лицензия — `Fonts/OFL-Montserrat.txt`.

Утро и дорогу Тимофея сопровождает `Reflection On Water`, школьный эпизод и встречу с Варей — `Timid Girl`. Школьная часть Серёги использует `No Tresspassing`, весь вечерний эпизод, включая закрытый клуб, — `Drown`. Меню звучит под `Afterword`. Внутри этих эпизодов музыка не переключается при каждой развилке. В момент удара, после него и в конце демо наступает тишина. Во время видео остаётся звук записи, после неё начинается школьная тема.

Тимофей находит уже мёртвую лису. Выбор «Заснять лису» открывает оригинальную 45-секундную запись с её собственным звуком. После окончания или кнопки «Продолжить» игра возвращается к тексту истории. Есть перемотка и другие штатные элементы управления видео; Escape возвращает к сюжету. При выборе пройти мимо ролик не запускается. Надпись с названием истории и счётчиком сцен убрана с игрового экрана.

## Содержимое

- `Prototype.html` — актуальный самостоятельный прототип.
- `Buttons/`, `Layout/`, `Location/` — исходные кнопки, макеты и фоны.
- `Musics/`, `Video/` — исходные аудио и видео.
- `Some game mockups on paper/` — фотографии бумажных макетов.
- `Archive/` — прежние HTML-версии и исходный ZIP; содержимое ZIP сохранено внутри архива.
- `ANALYSIS.md` — анализ структуры, сюжета и ограничений.

Все 73 файла из предоставленного RAR перенесены в корень репозитория с сохранением путей внутри папки `Schools Nowell`, имён и содержимого. Сам транспортный RAR не добавлен, его содержимое представлено распакованными файлами.
